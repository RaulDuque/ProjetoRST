# PROMPT 08 — CONTINGÊNCIA SE O MANEQUIM OU A CONVERSÃO FALHAREM

Ler `00_LEIA_PRIMEIRO.md` revisado. Usar este prompt apenas se a Etapa 02B não permitir preparar os recortes, ou se o piloto 03/04 falhar visual ou tecnicamente. A Etapa 02 mostrou que o rig é **reaproveitável com ajustes**, não que está totalmente aprovado.

**Restrição irrevogável:** a base visual do jogo é o protagonista aprovado **vestido**. Corpo nu 2D ou 3D não será criado como requisito. Não migrar do Rust/Bevy e não retornar ao gerador procedural de faixas da N41-B.

1. Identificar exatamente a falha observada: encaixe dos ombros, geometria 3D, projeção, oclusão da camisa/manga, cabelo, redução/paleta ou custo por pose. Citar evidências verificáveis.
2. Comparar alternativas práticas e pequenas: A. ajustar apenas o rig/oclusão; B. novo manequim 3D **invisível** simplificado para torso; C. produzir uma camada de armadura em ilustração 2D de alta resolução, reduzir e sobrepor à mesma base vestida. Não exigir redesenhar o personagem inteiro.
3. Para cada opção, explicar o que já existe, o que é reaproveitado, esforço por nova armadura, limitações e risco de inconsistência entre quadros.
4. Recomendar **um único experimento reversível** com stop gate visual claro. Não implementar três sistemas em paralelo, não criar novos itens em lote.

**Entregar apenas diagnóstico e plano do experimento. Não instalar, alterar produção, criar commits ou fazer push; aguardar decisão do proprietário.**
