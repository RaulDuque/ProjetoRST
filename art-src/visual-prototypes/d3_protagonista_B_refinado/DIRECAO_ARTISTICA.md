# Direção artística D3 — Protagonista B

## Identidade

Aristocrata gótico de fantasia sombria (direção B), com leitura de movimento
inspirada nas poses A:

- cabelo curto escuro + franja;
- casaco longo + ombreira;
- capa vinho assimétrica;
- botas;
- espada + bainha;
- vista lateral (prioritária);
- altura visual ~52 u; hurtbox 26×46 u intacta.

## Método declarado com honestidade

**Pixel construído em camadas (ferramenta local)**, não:

- downsample de conceitos gerados;
- “pixel art manual” pintada à mão quadro a quadro por um artista humano.

É um protótipo técnico de identidade estável para decidir se B1 ou B2 segue
para produção humana / híbrido Blender.
