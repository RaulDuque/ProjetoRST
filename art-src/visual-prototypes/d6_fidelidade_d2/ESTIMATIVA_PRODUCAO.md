# Estimativa de produção (intervalos)

| Trabalho | Hipótese |
|---|---|
| Finalizar protagonista (idle+run D2 modular) | 2–4 semanas arte |
| Armadura nova (malha final + weights) | 3–8 dias |
| Elmo | 1–2 dias |
| Capa | 1–2 dias |
| Espada / escudo | 0.5–1.5 dias cada |
| Adaptar peça aos clips (~22) | 0.5–2 dias / peça se sockets ok |
| Integração Bevy (camadas) | 3–6 dias |
| QA clipping | 1–3 dias / set |
| Acabamento 2D D2 | **maior custo**: horas/clip × camadas |

Automatizável: export, testes, compose.
Artístico: modelagem fina, pixel/paint-over, hair masks.

Inimigos humanoides podem reusar sockets/pipeline; **não** o mesmo rig necessariamente.
