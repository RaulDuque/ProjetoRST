# N3.2 — Ferramentas

Não há gerador local instalado. A GPU é uma RTX 4050 com 6 GiB. Nenhum modelo grande foi baixado. Hunyuan3D não foi usado. Nenhuma chave foi lida.

A ferramenta que respondeu foi o gerador de imagens do Cursor (`GenerateImage`). Ele gravou JPEG, sem alpha, e não informou modelo, semente nem licença. A transparência foi feita depois, num script local, por flood a partir dos cantos em pixels claros e quase neutros. Isso pode apagar uma lâmina clara que encoste no fundo. Não é pintura.

O Pixelorama continua sem sessão de pintura, como na N3.1.

Os arquivos privados do projeto não foram enviados. A vista lateral do conceito B foi reenviada ao mesmo gerador como referência das poses. Essa imagem tinha acabado de ser gerada para esta etapa.
