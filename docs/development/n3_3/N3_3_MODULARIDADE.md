# N3.3 — Modularidade

O corpo, a capa e a espada são três PNG. Uma ombreira de aço está desenhada no corpo, não como peça solta. Não há segunda armadura. Trocar o torso inteiro ainda exige outro desenho do corpo.

Os soquetes deste quadro podem ser reaproveitados se a pintura respeitar a mesma sola e a mesma mão. Não é a produção da N4.
