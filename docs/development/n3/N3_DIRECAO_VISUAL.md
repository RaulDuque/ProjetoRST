# N3 — Direção visual

O alvo continua o que a N1 descreveu: fantasia gótica, silhueta forte, arte original, legível quando pequena. "32/64 bits" aqui é o jeito do traço, não um limite de tamanho do sprite.

A figura desta prova é um corpo de lado, desenhado para a direita e espelhado para a esquerda. A armadura leve é um tabardo estreito, braços de pele e cabelo curto. A pesada é placa, ombreiras e elmo com crista. A capa é roxa e fica atrás. A espada é curta e reta. A lança é um cabo longo com ponta clara. O ouro `(232, 176, 64)` só existe nas armas, para o teste poder procurar uma arma desenhada dentro do corpo.

Isso não é o estilo final do Dark Castle. É uma figura de prova, com paleta fechada e contorno de um pixel. O proprietário ainda não aprovou o visual.
